# Msvc-Usuario

## Descripción
Microservicio de gestión de usuarios para Level-Up Gamer. Maneja el registro, autenticación y gestión de perfiles de usuarios.

## Funcionalidades
- Registro de usuarios
- Gestión de perfiles
- Validación de datos de usuario
- Integración con sistema de autenticación

## Configuración
- Puerto: 8002
- Base de datos: H2 (desarrollo)
- Perfil activo: dev

## Endpoints
- `/api/v1/usuarios` - Gestión de usuarios
- `/h2-console` - Consola de base de datos

## Tecnologías
- Spring Boot 3.4.5
- Spring Data JPA
- H2 Database
- OpenFeign
- Lombok
